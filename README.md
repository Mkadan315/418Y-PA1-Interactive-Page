# My Task List

Name: Mathew Kadanthod

## Description: 

My Task List is a simple task management application that allows users to add different tasks, select how much of a priority it is, and mark the tasks as completed, and delete the tasks afterwards.

## How to Run this Application:

You would open the index.html file in a web browser like Google Chrome in order to run this application.
